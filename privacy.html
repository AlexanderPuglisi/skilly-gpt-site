Informativa sulla privacy per Skilly GPT

Data di entrata in vigore: 6 febbraio 2026

Questo GPT, “Skilly FiveM ESX-QB (2026 PRO)”, è progettato per l'uso tecnico nello sviluppo del server FiveM e non raccoglie né memorizza dati personali degli utenti.

Utilizzo delle informazioni

  • Nessuna informazione personale viene raccolta, archiviata o condivisa.
  • Tutte le richieste API vengono utilizzate esclusivamente per convalidare e analizzare le risorse del server FiveM.

Strumenti di terze parti

Skilly GPT si integra con API private/locali come skilly.local, esportazioni BLDR.chat e validatori di risorse Lua/JS.

Sicurezza

Tutte le comunicazioni devono avvenire tramite HTTPS con autenticazione tramite chiave API quando necessario. Nessun dato viene registrato o condiviso esternamente.
